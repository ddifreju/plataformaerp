# Achados dos testes

Falhas encontradas pelos agentes de teste. Um bloco por falha, o mais novo
embaixo. Quem corrige marca **Situação** como "corrigido no PR #N".

Modelo:

```
### [Tarefa X9] Título curto da falha
- Gravidade: bloqueia | atrapalha | detalhe
- Onde: menu → tela
- Cargo e tela: dono@ · 1440 px
- Passos:
  1. …
  2. …
- Esperado: …
- Aconteceu: …
- Print: docs/testes/prints/…
- Agente: …
- Situação: aberto
```
